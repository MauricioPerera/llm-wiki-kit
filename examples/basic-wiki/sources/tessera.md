# Helix Robotics launches Tessera-1

Helix Robotics, a Barcelona-based startup, announced the commercial launch of
Tessera-1 on April 2, 2026. Tessera-1 is a mid-size autonomous warehouse robot
aimed at 3PL operators.

Tessera-1 implements a navigation framework Helix calls **Lattice-Nav**, which
blends occupancy maps with ephemeral object memory. Helix claims Lattice-Nav
cuts pick-and-place latency by 38% against their previous controller.
